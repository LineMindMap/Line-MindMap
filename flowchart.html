Build your chart

Add a shape, then drag it into position. Press Tab for a connected child or Ctrl+Enter for a sibling. Click an arrow to type its label or insert a cell. Connect joins existing cells.

Choose top-to-bottom or left-to-right, then Arrange to tidy the diagram. Ctrl+Tab also adds a sibling when your browser allows it. Drag empty space to pan. Use the zoom buttons or wheel to zoom. Double-click a shape to edit its text. Arrow keys move the selected shape.

Changes save in this browser. Download JSON for a portable, editable backup.
